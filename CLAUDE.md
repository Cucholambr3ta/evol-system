## Quality Guidelines

### Absolute Portability
All file paths must be **relative**. No absolute paths. Scripts and configs work
on any machine without modification.

### Zero Duplicates
Every piece of knowledge exists in exactly one place:
- **SSoT:** `.agent/workflows/` (versioned, never generated)
- **IDE outputs:** generated by `evol-adapt.sh` from SSoT
- **Registry:** `prompts/agents/registry.json` (auto-generated from core agents)

### Gated Pipeline
Never chain long flows without checkpoints. Require explicit "APPROVED" for
structural changes or phase transitions. Use `evol-gate` for HMAC-signed approvals.
